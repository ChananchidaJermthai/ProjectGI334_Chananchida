# เริ่มเล่น Colonization

เปิดโปรเจกต์ด้วย Unity 6000.6.6f1 แล้วเปิดฉาก `Assets/Scenes/Map01.unity` จากหน้าต่าง Project จากนั้นกด Play และ Begin expedition

## สิ่งที่ทำได้แล้ว

- ใช้ภาพ Terrain 11 แบบ ป่า 7 แบบ คน 20 แบบ เรือ 6 แบบ และภาพของ Native 8 ชาติจาก ZIP
- สำรวจแผนที่ Hex เลื่อนและซูมกล้อง เลือกยูนิต เดินตามเส้นทาง และจบเทิร์น
- ให้ Free Colonist สร้างเมือง และให้ Hardy Pioneer ถางป่า งานเสร็จเมื่อจบเทิร์น
- ขึ้นเรือ ลงเรือ และใช้ผลผลิตเมืองรับยูนิตหรือสร้างเรือเพิ่ม
- เปิด Asset collection เพื่อดูภาพทั้งหมด และ Native nations เพื่อดูธง ผู้นำ หมู่บ้าน และข้อมูลที่แนบมากับ Assets

## ทดลองสร้างเมืองแรก

1. เริ่มเกมแล้วเลือก Free Colonist ที่ชายฝั่ง หากเลือก Pioneer อยู่ ให้คลิกช่องเดิมอีกครั้งเพื่อสลับยูนิต
2. กด Found colony หรือ B
3. กด End turn เมืองจะสร้างเสร็จและเริ่มสะสม Food กับ Lumber
4. คลิกเมืองเพื่อดูของที่มี แล้วกด Recruit / build เมื่อมี Food อย่างน้อย 20 หรือ Lumber อย่างน้อย 20
5. เลือกคนหรือเรือที่ต้องการ เรือสร้างได้เฉพาะเมืองติดทะเล ยูนิตใหม่เริ่มเดินได้ในเทิร์นถัดไป

## ปุ่มควบคุม

| ปุ่ม | การใช้งาน |
| --- | --- |
| WASD / ลูกศร | เลื่อนกล้อง |
| ล้อเมาส์ | ซูม |
| กดเมาส์กลางค้างแล้วลาก | เลื่อนกล้อง |
| คลิกซ้าย | เลือกช่องหรือยูนิต คลิกซ้ำเพื่อสลับยูนิตในช่องเดียวกัน |
| คลิกขวา | เดินไปยังช่องเป้าหมาย |
| Tab | เลือกยูนิตถัดไป |
| B | ให้ Free Colonist วางแผนสร้างเมือง |
| P | ให้ Pioneer เริ่มถางป่า |
| Enter / Backspace | จบเทิร์น |

ขึ้นเรือโดยเลือกคนบนบกแล้วคลิกขวาไปยังเรือในช่องทะเลที่ติดกัน ลงเรือโดยเลือกเรือแล้วคลิกขวาช่องบกที่ติดกัน หรือกด Disembark
