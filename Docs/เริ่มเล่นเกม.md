# เริ่มเล่น Colonization

เปิดโปรเจกต์ด้วย Unity 6000.6.6f1 แล้วเปิดฉาก `Assets/Scenes/Map01.unity` จากหน้าต่าง Project จากนั้นกด Play และ Begin expedition

## สิ่งที่ทำได้แล้ว

- ใช้ภาพ Terrain 11 แบบ ป่า 7 แบบ คน 20 แบบ เรือ 6 แบบ และภาพของ Native 8 ชาติจาก ZIP
- สำรวจแผนที่ Hex เลื่อนและซูมกล้อง เลือกยูนิต เดินตามเส้นทาง และจบเทิร์น
- ให้ Free Colonist สร้างเมือง และให้ Hardy Pioneer ถางป่า งานเสร็จเมื่อจบเทิร์น
- ขึ้นเรือ ลงเรือ และใช้ผลผลิตเมืองรับยูนิตหรือสร้างเรือเพิ่ม
- เปิด Asset collection เพื่อดูภาพทั้งหมด และ Native nations เพื่อดูธง ผู้นำ หมู่บ้าน และข้อมูลที่แนบมากับ Assets

## ทดลองสร้างเมืองแรก

1. เริ่มเกมบนเรือ Caravel ซึ่งบรรทุก Free Colonist และ Hardy Pioneer ไว้แล้ว เลือกเรือและคลิกขวาช่องทะเลไปทางฝั่งซ้าย
2. เมื่อเรืออยู่ติดชายฝั่ง กด End turn ให้มี Movement พอ แล้วคลิกขวาช่องบกเพื่อให้คนลงเรือทีละคน ต้องเลือกเรืออีกครั้งก่อนลงคนถัดไป
3. จบเทิร์น เลือก Pioneer แล้วกด P เพื่อถางป่า จบเทิร์นอีกครั้งเพื่อให้งานเสร็จ
4. เลือก Free Colonist แล้วกด B จากนั้น End turn เพื่อสร้างเมือง ผู้ก่อตั้งจะกลายเป็นประชากรในเมือง
5. เลือกเมืองแล้วกด Open town [T] หรือปุ่ม T ยูนิตบกที่ว่างอยู่บนช่องเมืองจะเข้ามาเป็นประชากรด้วย
6. ลากไอคอนจากพื้นที่ว่างงานซ้ายล่างไปยัง Hex รอบเมืองทั้ง 6 ช่องด้านขวาบน ย้ายระหว่างช่องได้ และลากกลับพื้นที่ว่างงานได้
7. กด End turn ในเมืองเพื่อรับ Food/Lumber ตามจำนวนที่แสดงใน Production จากนั้น Exit town เพื่อกลับแผนที่
8. รับคนหรือสร้างเรือเพิ่มผ่าน Recruit / build โดยใช้ Food 20 หรือ Lumber 20 เรือสร้างได้เฉพาะเมืองติดทะเล ยูนิตใหม่เริ่มเดินได้ในเทิร์นถัดไป

## ปุ่มควบคุม

| ปุ่ม | การใช้งาน |
| --- | --- |
| WASD / ลูกศร | เลื่อนกล้อง |
| ล้อเมาส์ | ซูม |
| กดเมาส์กลางค้างแล้วลาก | เลื่อนกล้อง |
| คลิกซ้าย | เลือกช่องหรือยูนิต คลิกซ้ำเพื่อสลับยูนิตในช่องเดียวกัน |
| คลิกขวา | เดินไปยังช่องเป้าหมาย |
| Tab | เลือกยูนิตถัดไป |
| B | ให้ Free Colonist วางแผนสร้างเมือง |
| P | ให้ Pioneer เริ่มถางป่า |
| T | เปิดเมืองที่เลือก |
| Escape | ออกจากหน้าจอเมือง |
| Enter / Backspace | จบเทิร์น |

ขึ้นเรือโดยเลือกคนบนบกแล้วคลิกขวาไปยังเรือในช่องทะเลที่ติดกัน ลงเรือโดยเลือกเรือแล้วคลิกขวาช่องบกที่ติดกัน หรือกด Disembark
