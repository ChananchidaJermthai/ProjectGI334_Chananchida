# วิดีโอเล่นเกมและจัดคนงานในเมือง

ไฟล์วิดีโอที่บันทึกอยู่ใน `Deliverables/Colonization_Gameplay_Walkthrough.mp4` พร้อมรายการเวลาของแต่ละขั้นตอนใน `Deliverables/Walkthrough_Chapters.txt`

วิดีโอเป็นการบันทึกการรันเกมใน Unity Play Mode แบบอัตโนมัติ ความละเอียด 1920×1080 ที่ 20 fps ไม่มีเสียง ไม่ใช่ภาพนิ่งประกอบกัน ระบบบันทึกเรียกคำสั่งเล่นเกมและส่งเหตุการณ์ลากผ่าน UI Event System พร้อมตรวจว่าช่องที่มองเห็นรับการ Drop และสถานะคนงานเปลี่ยนตามจริง

ลำดับที่สาธิต:

1. เริ่มเกมและแสดงแผนที่ทั้งหมด โดย Prefab Hex เปิด `Reveal On Start`
2. เรือ Caravel บรรทุก Colonist และ Pioneer เดินทางจากทะเลเข้าชายฝั่ง
3. ลงเรือทั้งสองคนและจบเทิร์นเพื่อคืน Movement
4. Pioneer ถางป่า และ Colonist สร้างเมือง โดยงานเสร็จในเทิร์นถัดไป
5. เปิดหน้าจอเมือง เห็น Hex รอบเมือง 6 ช่องด้านขวาบนและพื้นที่ว่างงานซ้ายล่าง
6. ลากคนงานออกจากพื้นที่ว่างงาน ไปยัง Hex ทั้ง 6 ช่อง ย้ายระหว่างช่อง และย้ายกลับพื้นที่ว่างงาน
7. จัดคนลงช่องป่า จบเทิร์น และตรวจจำนวนผลผลิตที่เพิ่มขึ้น
8. ออกจากเมืองกลับสู่แผนที่

ข้อมูลตั้งต้นใช้ Seed 334 โดยกำหนดชายฝั่งสำหรับขึ้นบกและป่าอีกหนึ่งช่องใกล้เคียง เพื่อให้สาธิตการถางป่าและผลผลิตไม้ได้ซ้ำอย่างแน่นอน
